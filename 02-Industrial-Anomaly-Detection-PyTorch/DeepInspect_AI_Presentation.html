البنية المعمارية للشبكة العصبية

تصميم Convolutional Autoencoder (CAE)

1. المشفر (Encoder Pipeline)
Input: [3, 256, 256] (196,608 values) ➔ Conv2D(3, 32) + BN + ReLU + MaxPool ➔ [32, 128, 128] ➔ Conv2D(32, 64) + BN + ReLU + MaxPool ➔ [64, 64, 64] ➔ Conv2D(64, 128) + BN + ReLU + MaxPool ➔ [128, 32, 32] ➔ Conv2D(128, 256)+ BN + ReLU + MaxPool ➔ [256, 16, 16] ➔ Flatten(65,536) ➔ Linear ➔ Latent Vector: 128
⚡ نسبة ضغط تفوق 99.9% لتجريد الميزات الأساسية وإجبار الشبكة على فهم الهيكل بدلاً من الحفظ السطحي.
2. المفكك (Decoder Pipeline)
Latent: [128] ➔ Linear ➔ Reshape [256, 16, 16] ➔ ConvTranspose2D(256, 128) + BN + ReLU ➔ [128, 32, 32] ➔ ConvTranspose2D(128, 64) + BN + ReLU ➔ [64, 64, 64] ➔ ConvTranspose2D(64, 32) + BN + ReLU ➔ [32, 128, 128] ➔ ConvTranspose2D(32, 3) + Sigmoid() ➔ [3, 256, 256]
✨ دالة Sigmoid في المخرج تضمن تقييد قيم البكسلات في النطاق الفيزيائي المعياري [0.0, 1.0].

خوارزمية توطين العيب وتوليد الخريطة الحرارية

📐
1. حساب الفرق التربيعي
diff = (Input - Recon) ** 2 residual = mean(diff, dim=RGB)
حساب الفارق في كل بكسل عبر قنوات الألوان الثلاث للحصول على مصفوفة أخطاء ثنائية الأبعاد (256x256).
🌊
2. الترشيح المكاني الغاوسي
smoothed = cv2.GaussianBlur( residual, (7, 7), sigma=4.0 ) score = max(smoothed)
تطبيق فلتر Gaussian لإلغاء ضوضاء حساس الكاميرا والتركيز على العيوب المترابطة مكانياً.
🎨
3. الدمج الحراري (Jet Map)
heatmap = cv2.applyColorMap( norm, cv2.COLORMAP_JET ) overlay = 0.5*Orig + 0.5*Heat
تلوين العيب باللون الأحمر الساطع ودمجه مع الصورة الأصلية لتقديم تفسير بصري فوري لمهندس الجودة.
